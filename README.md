# Particle Galaxy 🔬

**▶ [Explore it](https://renrenmimi.github.io/particle-galaxy/)** — runs in your browser, nothing to install.

An interactive n-body particle sandbox. Pick a starting configuration, then watch gravity do the rest.

## Presets

| Key | Scenario |
|-----|----------|
| `1` | Spiral |
| `2` | Binary |
| `3` | Collision |
| `4` | Cloud |

## Controls

- **Trails** — toggle motion trails
- **Vectors** — draw velocity vectors
- **Field** — visualize the gravitational field
- **Merge** — let colliding particles combine
- **Reset** (`R`) — restart the current scenario
- **Screenshot** — save the current frame

## Tech

Single-file HTML5 Canvas app. No build step, no dependencies.
